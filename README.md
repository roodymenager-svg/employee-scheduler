# JCL Employee Scheduler

A web-based employee scheduling application built for managing staff assignments, shift planning, and email notifications.

## Features

- Secure user login with Firebase Authentication
- Cloud data storage with Firestore
- Import employee lists from Excel
- Automatic schedule saving
- Export and backup schedules
- Email preparation for scheduled employees
- Responsive web interface

## Technologies

- HTML5
- CSS3
- JavaScript
- Firebase Authentication
- Cloud Firestore
- Firebase Hosting
- Git
- GitHub

## Live Demo

## Installation

Clone the repository

```bash
git clone https://github.com/roodymenager-svg/jcl-employee-scheduler.git
```

Open `index.html`

or deploy with Firebase.
